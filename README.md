# BookShelf

**Student Name:** Albarillo, Buena Ann D.
**Course and Section:** Web System and Technologies 2 (ITE311) - F1

## Project Description
BookShelf is a simple web-based reading list manager. Users can add books with an author and
genre, mark them as read, delete them, and search or filter the list by genre. Each feature
was developed in its own Git branch and merged into main as part of Laboratory Activity No. 2
(Version Control Using Git and GitHub).

- CSS
- JavaScript
- Git and GitHub
